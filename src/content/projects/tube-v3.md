<h2 class="text-xs font-mono tracking-[0.4em] text-cyan-400 mb-6 uppercase">Overview</h2>
<p class="text-zinc-300 text-2xl leading-relaxed font-light">
This year, as the 4th of July was getting closer, I thought of how I could improve the tube. Two things immediately came to mind: first, my arms got tired from paddling the previous year, so building a pedal boat would make moving much easier. Second, the PVC cube actually started to fall apart near the end of the day, so I wanted a structure I could trust more. A sturdier structure was also needed to support the added weight of the new pedal system.
</p>
</div>
<div class="md:col-span-4 border-l border-zinc-800/80 pl-8 flex flex-col justify-center">

<ul class="flex flex-col gap-6">
<li>
<span class="text-white font-bold block text-lg mb-1">Improved Structure</span>
<span class="text-zinc-400 text-sm leading-relaxed">Half wood, half pvc cube</span>
</li>
<li>
<span class="text-white font-bold block text-lg mb-1">Cooler for Drinks</span>
<span class="text-zinc-400 text-sm leading-relaxed">Ice cold drinks all day</span>
</li>
<li>
<span class="text-white font-bold block text-lg mb-1">Snack Box</span>
<span class="text-zinc-400 text-sm leading-relaxed">Built-in storage for snacks</span>
</li>
<li>
<span class="text-white font-bold block text-lg mb-1">Pedal Power</span>
<span class="text-zinc-400 text-sm leading-relaxed">Powered with legs using a cut up bike, driveshaft, and propeller</span>
</li>
</ul>
</div>

<h3 class="text-4xl font-bold text-white">Bevel Gear</h3>
<p class="text-zinc-400 text-lg leading-relaxed">
The hardest part of this project was figuring out how to take the power from pedaling and turn it 90 degrees to push the propeller. I ended up using two bike wheels to create a custom bevel gear.
</p>

<h3 class="text-4xl font-bold text-white">Propeller</h3>
<p class="text-zinc-400 text-lg leading-relaxed">
The bevel gear would spin a PVC driveshaft that reached the back of the boat, where the propeller was attached.
</p>

<h3 class="text-4xl font-bold text-white">It Floats!</h3>
<p class="text-zinc-400 text-lg leading-relaxed">
A lot of people were skeptical that this would even float, so that alone was a win in my book. Unfortunately, the driveshaft did end up having problems and broke early in the day. However, I was still able to float with my drinks and snacks while staying shaded all day.
